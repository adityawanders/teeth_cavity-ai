# Dataset

## Overview

This directory contains information about the image dataset used in the Teeth Cavity Detection using Artificial Intelligence project. There are a total 4048 images in the dataset.

The dataset is hosted externally on Google Drive.

## Dataset Download

**Google Drive Link: https://drive.google.com/drive/folders/15dAQXuWsDwHmBphjzQEgyNbxMUsIxXQ0

## Dataset Format

- File format: ZIP archive
- Data type: Dental images
- Purpose: Training and evaluating the AI model

## Instructions to Access the Dataset

1. Open the Google Drive link above.
2. Download the ZIP file.
3. Extract the archive.
4. Organize the extracted images according to the structure expected by the project notebook.
5. Update the dataset path in the notebook if necessary.

## Usage

The dataset is used for image preprocessing, model training, and evaluation.
